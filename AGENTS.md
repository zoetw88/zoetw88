# Profile Repository Rules

This special repository renders Zoe's public GitHub profile from `README.md`.

- Keep the profile concise, personal, and evidence-based.
- Store visual assets locally under `assets/`; avoid external badge services.
- Prefer accessible SVGs that work in GitHub light and dark themes.
- Preserve `prefers-reduced-motion` behavior for animation.
- Validate README changes with GitHub's Markdown API and visually inspect the
  rendered branch before publishing.
