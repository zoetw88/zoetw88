# GitHub brand alignment

## Goal

Make Zoe's public GitHub profile and self-owned public repositories read as one portfolio while keeping each repository's purpose clear.

## Brand spine

- Senior backend engineer building practical AI products.
- AI meets backend reality: permissions, evaluation, failure paths, privacy, and measurable feedback loops.
- Direct, evidence-backed language without hype.
- Personal site is the canonical writing and identity surface: <https://zoe-site-ten.vercel.app>.

## Acceptance criteria

- [x] Profile headline and badges match the personal site's positioning and palette.
- [x] Every self-owned public repository has a clear first-screen purpose.
- [x] Product and tool READMEs link back to Zoe without displacing the repository's own story.
- [x] Public metadata has a description, useful topics, and a homepage where one exists.
- [x] Personal data, credentials, private source, private prompts, and private job-search records are absent.
- [x] Existing license boundaries are preserved; missing licenses are reported rather than invented.
- [x] Markdown links and repository status are verified before merge.

## Scope

- `zoetw88/zoetw88`
- `zoetw88/ai-workflow`
- `zoetw88/job-tracker-skill`
- `zoetw88/tcf-canada-showcase`
- `zoetw88/speakup-sd-showcase`
- `zoetw88/12wy-tracker`
- `zoetw88/commit-time-machine`

Public forks and private repositories are out of scope for content edits.
